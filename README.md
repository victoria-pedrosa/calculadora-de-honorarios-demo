# Demonstração — Calculadora de precificação de honorários

> Projeto de portfólio de **Victória Pedrosa**. **Demonstração** de calculadora de precificação de honorários — versão com dados fictícios (nomes, CNPJs, e-mails e IDs internos substituídos).

## Problema de negócio
Precificar honorários dependia de cálculo manual e da experiência de cada pessoa, gerando propostas inconsistentes.

## Antes x depois
| | Antes | Depois |
|---|---|---|
| Como é feito | Preço calculado em planilhas soltas, sem régua única. | Web app calcula o honorário a partir de uma base mínima (CNPJ, atividade, regime), separada do financeiro por segurança. |

## Ganho
- Propostas padronizadas e rápidas, sem expor dados financeiros da carteira.

## Tecnologias
Google Apps Script, Google Sheets, HTML/JavaScript, Web App (HtmlService)

## Arquivos
- `Codigo.gs`
- `Index.html`

## Como usar
Crie um projeto no Google Apps Script, copie os arquivos `.gs`/`.html` e configure as Propriedades do script indicadas no código.
